# Product context

Nimantha Hewawasam's personal software-development portfolio serves prospective clients, employers, and engineers. Visitors should see actual work quickly, understand his contribution, inspect screenshots, read his writing, and contact him directly.

The public site contains Home, Work, project details, About, Services, Blog/article details, and Contact. The hero's opening position and name/portrait/introduction composition are retained. Work leads the browsing journey. Project screenshots and client quotations must be genuine; missing assets are represented honestly.

Supabase Auth and an admins membership table protect the content CMS. Existing project, service, skill, process, brand, blog, and testimonial data remain editable. Original project files are immutable public portfolio assets; previews are separate responsive derivatives. Customer feedback is manually published.

Stack: Next.js App Router, React, TypeScript, Tailwind, Supabase database/Auth/Storage, and self-hosted Manrope. Existing GitHub Actions deploys a standalone Next.js application to Namecheap/cPanel. No paid external image service, contact-form backend, or new authentication system is required.

Success: visitors can navigate Home → Work → project screenshots → Contact; admin can maintain real images and feedback; originals retain their bytes; navigation and gallery controls work on mobile and keyboard; the site remains legible and restrained.
